Privacy policy

Channel Publisher · Last updated 14 November 2026

Who uses this app

Channel Publisher is a private tool used only by its owner, on YouTube channels the owner owns. It has no other users and offers no public sign-up.

What data it accesses

With the owner's permission, granted through Google's sign-in screen, the app uses YouTube API Services to:

  • upload videos, set their details (title, description, captions, thumbnail, playlists, schedule) and manage comments on the owner's own channels (youtube.force-ssl scope)
  • read analytics and reach reports for the owner's own channels (yt-analytics.readonly scope)

It does not access Gmail, Drive, contacts or any other Google data, and it does not access other people's channels.

How the data is used

Data is used only to publish the owner's videos and to produce private performance reports for the owner. It is never sold, shared with third parties, used for advertising, or used to train AI models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

The sign-in credential (OAuth token) is stored encrypted as a private secret in the owner's GitHub account, or on the owner's own computer. Analytics reports are kept in the owner's private storage. No viewer or third-party personal data is collected or stored.

Retention and deletion

Analytics reports are kept only as long as the owner needs them for their own channels. The owner can revoke the app's access at any time at myaccount.google.com/permissions, which stops all access immediately. Stored tokens are then deleted.

Third-party terms

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Contact

Questions about this policy can be raised through the issue tracker of the project repository.
